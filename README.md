### 🧪 Research Projects / 研究项目

<table>
  <tr>
    <td align="left" width="600">
      <h3>🛰️ Remote-sensing Object Counting via Foundation Models</h3>
      <b>Jun 2025 – Aug 2026</b> · with Prof. LI Weihong & ZHANG Zhibang<br>
      Few-shot remote-sensing object counting combining <b>Grounding DINO + SAM 3 + learning-to-rank</b>. Designed <b>Glank</b>, a counting model for aerial imagery.<br>
      📄 <i>IEEE Geoscience and Remote Sensing Letters</i>, 2026<br>
      <i>基于基础模型的少样本遥感目标计数，结合 Grounding DINO + SAM 3 + 学习排序，提出计数模型 Glank。</i><br>
      <a href="https://github.com/reowinreo/My_ml_portfolio/tree/main/Remote-sensing%20Object%20Counting%20via%20Foundation%20Models"><img src="https://img.shields.io/badge/Code-2563eb?style=flat-square&logo=github&logoColor=white" alt="code"/></a>
    </td>
  </tr>
  <tr>
    <td align="left" width="600">
      <h3>🧠 Knowledge Distillation Based on Learning to Rank</h3>
      <b>Nov 2024 – May 2025</b> · with Prof. LI Weihong & ZHANG Zhibang<br>
      Lightweight model compression for remote-sensing foundation models via distillation, with learning-to-rank weighting for multi-task training.<br>
      <i>通过知识蒸馏对遥感基础模型做轻量化压缩，并结合学习排序权重进行多任务训练。</i><br>
      <a href="https://github.com/reowinreo/My_ml_portfolio/tree/main/Knowledge%20Distillation%20Based%20on%20Learning%20to%20Rank"><img src="https://img.shields.io/badge/Code-7c3aed?style=flat-square&logo=github&logoColor=white" alt="code"/></a>
    </td>
  </tr>
  <tr>
    <td align="left" width="600">
      <h3>🌍 Remote-sensing Scene Classification Based on Deep Learning</h3>
      <b>Jan 2024 – Oct 2024</b> · with Prof. LI Weihong & ZHANG Zhibang<br>
      Scene classification with CNN feature extraction + SVM, end-to-end fine-tuning, metric learning, and <b>R4C</b> multi-label ranking.<br>
      📄 <i>Pattern Recognition</i> (under review)<br>
      <i>基于 CNN 特征提取 + SVM、端到端微调、度量学习，以及 R4C 多标签排序的遥感场景分类。</i><br>
      <a href="https://github.com/reowinreo/My_ml_portfolio/tree/main/Remote-sensing%20Scene%20Classification%20Based%20on%20Deep%20Learning"><img src="https://img.shields.io/badge/Code-f59e0b?style=flat-square&logo=github&logoColor=white" alt="code"/></a>
